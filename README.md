## 输入与输出

输入：品牌事实、产品、目标客户、地区/语言、常见咨询；已有问题和本次需要的数量。

输出：question-pool.csv：question_id,question,language,market,stage,origin,priority,reason,evidence_needed；另附建议首测题组。

## 工作步骤

1. 确认实际业务边界：服务对象、能交付什么、不做什么；缺资料时使用已知范围并标注假设。
2. 先保留真实咨询原话，再生成候选问题；分品牌认知、无品牌需求、方案比较、采购验证、使用维护。
3. 去重同一意图但保留地区、场景与采购阶段差异；不强行把品牌塞进所有问题。
4. 每题赋稳定ID Q001等；保留原题。按业务相关性、决策价值、可提供证据排序，说明依据。
5. 固定一组基线题用于后续同条件复测；新增问题不覆盖旧ID。

## 使用方法

这是供支持 SKILL.md 的 AI 工具读取的工作流技能，不是独立网站或浏览器插件。

1. 从仓库 **Code → Download ZIP** 下载并解压，保留全部文件及目录结构。
2. 按所用 AI 工具的安装方式导入该目录；是否兼容以实际导入和运行结果为准。
3. 提供所需材料并明确调用 `seoguan-question-pool`。支持 `$技能名` 的宿主可使用下方示例。

依赖：不要求 Python、GEO 后台账号或付费 API。需要宿主具备读取所提供材料的能力；宿主模型服务可能有费用。
